S

Static

The default position value. Elements follow normal document flow. Offset properties (top, right, bottom, left) have no effect.

Key Properties

Flow: Normal Document Flow
Offset: Not Applicable
Stacking: Default
Static Positioning Demo
Static

This element cannot be moved with positioning properties.

.element {
  position: static;
  /* top, right, bottom, left have NO effect */
}
R

Relative

Positioned relative to its normal position. Offset properties move it from original location. Original space in document flow is preserved.

Key Properties

Flow: Space Preserved
Offset: Top, Right, Bottom, Left
Reference: Original Position
Relative Positioning Demo
Relative

Moved 25px from top and left of original position. Original space remains reserved.

.element {
  position: relative;
  top: 25px;
  left: 25px;
}
A

Absolute

Removed from normal document flow. Positioned relative to nearest positioned ancestor. If none exists, uses initial containing block.

Key Properties

Flow: Removed
Offset: Top, Right, Bottom, Left
Reference: Positioned Ancestor
Absolute Positioning Demo
Parent Container (position: relative)
Absolute

Positioned 30px from top and right of parent container.

.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 30px;
  right: 30px;
}
F

Fixed

Removed from normal document flow. Positioned relative to viewport. Stays in same position during scrolling. Perfect for headers, modals, and navigation.

Key Properties

Flow: Removed
Offset: Top, Right, Bottom, Left
Reference: Viewport
Fixed Positioning Demo
Fixed

This element stays fixed to bottom-right of viewport. Scroll to see it remain in position.

.element {
  position: fixed;
  bottom: 30px;
  right: 30px;
  z-index: 1000;
}
ST

Sticky

Hybrid of relative and fixed positioning. Acts as relative until crossing specified threshold, then becomes fixed. Excellent for sticky headers and navigation.

Key Properties

Flow: Relative until threshold
Offset: Defines stickiness threshold
Reference: Scroll Container

Aspect Static Relative

Use Case Default positioning Minor adjustments, z-index context
