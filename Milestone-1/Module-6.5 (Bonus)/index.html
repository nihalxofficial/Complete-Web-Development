CSS :nth-child() Pseudo-class

A comprehensive guide to the powerful CSS selector for targeting elements based on their position

Syntax & Parameters

The :nth-child() pseudo-class matches elements based on their position among siblings.

:nth-child(an+b)

Parameters:

  • a - Cycle size (integer)
  • n - Counter (starts at 0)
  • b - Offset value (integer)
  • The formula selects every ath child starting from position b

Keyword values:

  • odd - Selects odd-numbered elements (1, 3, 5, ...)
  • even - Selects even-numbered elements (2, 4, 6, ...)

Common Examples

Select every 3rd element:

li:nth-child(3n) { color: red; }

Select every 2nd element starting from the 1st:

div:nth-child(2n+1) { background: blue; }

Select the first 3 elements:

p:nth-child(-n+3) { font-weight: bold; }

Select elements starting from the 4th:

tr:nth-child(n+4) { opacity: 0.8; }

Select only the 5th element:

span:nth-child(5) { border: 2px solid green; }

Practical Applications

  • Zebra-striping tables: Alternate row colors for better readability
  • Grid layouts: Control margins/padding on specific columns
  • Navigation menus: Style specific menu items differently
  • Image galleries: Create mosaic layouts with varying sizes
  • Form styling: Highlight every other form field for better scanning
  • Responsive design: Change layout at specific breakpoints based on item count
Note: The count includes all children, not just elements of the same type. Use :nth-of-type() if you need to filter by element type.
